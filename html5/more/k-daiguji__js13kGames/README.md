# js13kGames

---

## Setup

---

1. Clone repository

```
git clone https://github.com/k-daiguji/js13kGames.git
```

1. Change mode setup.sh

```
chmod +x setup.sh
```

1. Run setup.sh

```
./setup.sh
```

## Prompts

---

- Lint

  ```
  npm run lint
  ```

- Format

  ```
  npm run format
  ```

- Test

  ```
  npm test
  ```
