## Description
Gnomes have stolen another rainbow and now you have to restore it.

## Gameplay
Match colors to gather 30 of each. Gnomes will try to steal colors you gathered. You can fend them off by spending colors. You can refresh board with “Refresh” button (cost 1 of each color).

Gradually stronger gnomes will appear to steal your rainbow.

Enemy types:
- Gnome - typical gnome: small, slow and clumsy
- Gnome thief - faster than normal gnome, steals colors from the board
- Gnome warrior - stronger and tougher than regular gnome
- Gnome knight - gnome elite warrior
- Gnome wizard - temporary freeze colors on board

## Controls
Mouse / touchscreen You can choose between 2 methods to select and gather colors:
- releasing mouse / touch,
- confirming with “Match” button

## Building game
To run dev server use ```npm run dev``` command.

To build and zip game use ```npm run build``` command.

The build HTML file and it's zip file will be in ```build``` folder
