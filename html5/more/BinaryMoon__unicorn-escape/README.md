# Unicorn Escape

Unicorn Escape is a tiny metroidvania-style adventure game made for the 2026 [js13kGames](https://js13kgames.com/) competition.

The theme for 2026 was **Rainbows and Unicorns**, so naturally I made a game about a unicorn trapped in a cave.

Your goal is to explore the cave, find the missing colours of the rainbow, and use the abilities they unlock to find your way back to the surface.

The entire game (when zipped) fits within the 13kb js13k size limit.

## BeepMicro

Unicorn Escape was made using **BeepMicro**, my tiny JavaScript game engine designed specifically for making very small browser games.

**[BeepMicro on GitHub](https://github.com/BeepMini/BeepMicro)**
