# 参与改进

感谢你帮助完善岭南游园会。可以从小改动开始：修复手机触控问题、补充键盘提示、调整难度、优化插画，或为文化介绍补充可靠来源。

1. 先在 Issue 中描述问题、复现步骤或设计建议；小修正也可以直接提交 Pull Request。
2. 修改后，请至少在桌面和手机宽度下试玩对应游戏，检查开始、胜负、重开和计时器。
3. 保持三个游戏可独立打开，并使用仓库内资源。新增外部资源时说明用途、来源和许可。
4. 不要提交个人信息、扫描结果、账号凭据、密钥或他人未经授权的作品。
5. Pull Request 请写清改动内容、测试方式和截图；涉及文化事实时附上可核对的来源。

当前项目是纯静态网页，可直接打开 `index.html` 开始试玩。游戏页面之间通过相对链接导航。
