# 岭南游园会 · Lingnan Culture Mini Games

三款以岭南文化为灵感的浏览器小游戏。项目由原有单页游戏原型整理而来，加入统一入口、离线插画、响应式布局及更完整的游戏状态处理。所有游戏使用原生 HTML、CSS 和 JavaScript，无需构建工具。

## 立即试玩

在线打开：[岭南游园会试玩页](https://lon972.github.io/lingnan-culture-mini-games/)。

直接打开 [`index.html`](index.html)，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。游戏资源都在仓库内，加载后无需外部图片或样式服务。

## 三款游戏

| 游戏 | 玩法 | 标准时间 |
| --- | --- | --- |
| [大湾区寻火炬](寻火炬.html) | 在湾区地标主题场景中寻找火炬 | 90 秒 |
| [岭南建筑拼图](岭南建筑拼图.html) | 选择陈家祠、骑楼或镬耳屋，把 16 块拼图放回原位 | 120 秒 |
| [岭南美食连连看](连连看.html) | 翻开卡片，配对 20 种广府、潮汕与客家美食 | 150 秒 |

拼图中的建筑图像是为游戏绘制的**示意插画**，不代表建筑实景。游戏中的文化介绍用于启发探索，欢迎通过 Issue 或 Pull Request 补充可靠来源和更准确的表述。

## 活动规则边界

原活动设定提到了每日参与次数和“火力值”。本仓库是独立的本地游戏演示，不包含账户、每日次数限制、跨游戏积分或线上兑奖系统；页面内成绩只用于当前游戏体验。
